Built with TypeScript, Next.js, React, Tailwind CSS, SQLite, Firebase Hosting, Google Cloud Run and OpenAI. The deterministic engine includes 52 controls across five rule packs. OpenAI is used only for optional explanations of an existing finding. It cannot change a scan verdict or evidence ledger.

Validation: 461 engine tests and 45 integration checks against the hosted app. The 50-case in-house benchmark measures regressions, not general real-world accuracy. Static analysis cannot prove that a safeguard works in production or establish legal compliance.

This is a narrated walkthrough of actual hosted screens using bundled sample data. The earlier timestamp in the sample history is illustrative; both fixture scans are real engine output. Narration is AI-generated using OpenAI, with synchronized English captions. Claude and OpenAI Codex assisted with development and documentation.

Public demo workspaces reset after 24 hours or a service restart. Export any reports you want to keep. Use self-hosting for private code and durable storage.

Annex is a technical evidence tool, not legal advice, a certification or a conformity assessment.
