Live app: https://annex-evidence.web.app
No signup, password or API key is required.

1. Select Try the demo, then Enter the demo workspace. Four sample systems appear in your own workspace.
2. Open HireFlow. Confirm that the overview flags emotion inference in recruitment and cites Article 5(1)(f).
3. Open Evidence. Search for human oversight, change the rule-pack filter, and inspect the finding and source references. The audience buttons request an AI explanation; if the provider is unavailable, the original finding is shown explicitly.
4. Open Annex IV dossier. Review the unresolved human questions and download Markdown or printable HTML. German and French options translate headings and front matter, not every finding.
5. Open Remediation and download the patch. Templates are a starting point and do not automatically close the findings.
6. Open History to inspect the illustrative regression between two real fixture scans. The earlier timestamp is simulated.
7. Return to Systems and open HireFlow v3. It is high risk, with the prohibited path removed and remaining gaps still visible.
8. Open Share and View it to inspect the public summary. Source snippets are omitted. Copy link gives a full URL.
9. In Settings, change or clear turnover and employee count, save, and re-scan to update the exposure model. You can export the workspace and erase its data.
10. Add system accepts a public GitHub repository. Private code and GitHub tokens require self-hosting.

Limits: the public demo has temporary storage, a 12-system limit per workspace, bounded archive downloads and capped AI usage. Demo data expires after 24 hours or a Cloud Run restart. Download artifacts you want to keep. Static analysis is not legal advice or a conformity assessment. The benchmark is an in-house regression corpus.
